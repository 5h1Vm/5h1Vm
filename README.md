## 🛡️ Flagship Projects

### 🔒 [HonestBackup](https://gitlab.com/5h1Vm/HonestBackup)
*Encrypted SaaS Backup & Retention Platform | Python, Azure, Docker*
- 3-2-1-1-0 ransomware-resistant backup platform collecting Microsoft 365 (audit, Defender, sign-ins), Cloudflare, and Notion.
- Uses age-encryption with SHA-256 verification and Graph API delta tokens (reducing routine payloads from ~80 MB to ~1 MB).
- Running in production to solve multi-year compliance retention gaps.

### 🔍 [SusCheck](https://gitlab.com/5h1Vm/SusCheck)
*Pre-Execution Security Orchestration Engine | Python, CI/CD, Threat Intel*
- Multi-engine pre-flight static analysis pipeline aggregating Semgrep, Bandit, Checkov, Gitleaks, VirusTotal, and AbuseIPDB.
- Correlates multi-scanner outputs into a unified Risk Index with AI-assisted triage.

### 🚛 [Transport-ERP](https://gitlab.com/5h1Vm/Transport-ERP)
*Enterprise Fleet, Logistics & Route Accounting Platform | Python, Next.js, PostgreSQL*
- Full-stack ERP handling vehicle telemetry, route optimization, audit logs, and P&L financial ledger validation.

### 🧠 [VolatileAI](https://gitlab.com/5h1Vm/VolatileAI)
*Automated Memory Forensics & Malware Analysis | Python, Volatility3, AI*
- Memory forensics pipeline integrating Volatility framework artifacts with automated AI classification to accelerate DFIR investigations.

### 🧪 [chemical-ai](https://gitlab.com/5h1Vm/chemical-ai)
*AI-driven Chemical & Compound Threat Detection | Python, Deep Learning*
- Neural network classifier identifying hazardous chemical and molecular structures from spectral and structural datasets.

### 🎯 [memdmp-chal-Razzify](https://gitlab.com/5h1Vm/memdmp-chal-Razzify)
*Forensics CTF Challenge Design | Volatility, Linux/Windows Forensics*
